# Подключение регистрации (Supabase, бесплатно)

1. Зайдите на supabase.com, создайте аккаунт и новый проект (New project). Запомните пароль базы, в приложении он не нужен.
2. Откройте SQL Editor, вставьте содержимое файла `supabase/setup.sql` и нажмите Run. Это создаст таблицу, где каждый пользователь видит только свою строку.
3. Project Settings → API: скопируйте Project URL и публичный ключ (anon или publishable). Секретный ключ (service_role / secret) сюда не вставлять.
4. Впишите их в файл `config/cloud.json`: `{"url": "https://вашпроект.supabase.co", "key": "публичный_ключ"}`. Публичный ключ можно хранить в репозитории: данные защищают правила из setup.sql.
5. Authentication → URL Configuration: Site URL укажите `https://yuranagrebeckiy.github.io/investglass/`, так ссылки из писем будут вести на сайт.
6. Authentication → Sign In / Providers → Email: по желанию отключите «Confirm email», тогда вход будет сразу после регистрации. Если оставить, нужно подтвердить почту по письму. Встроенная почта Supabase имеет низкий лимит писем, для многих пользователей нужен свой SMTP.

После этого нажмите «👤» в приложении: там появится вход и регистрация.
