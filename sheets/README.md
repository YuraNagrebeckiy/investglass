# Сохранение данных в Google Таблицу

Когда вы входите под своим именем и паролем, журнал, подборки, уведомления, избранное и рисунки сохраняются в вашей Google Таблице и открываются на любом устройстве. Настройка занимает около 5 минут.

1. Создайте новую Google Таблицу (sheets.new). Название любое, например InvestGlass.
2. В таблице откройте Расширения → Apps Script. Удалите весь код, вставьте содержимое файла `sheets/Code.gs` и сохраните.
3. Нажмите Развернуть → Новое развёртывание → тип «Веб-приложение». Выполнять от имени: «Я». У кого есть доступ: «Все». Нажмите «Развернуть» и разрешите доступ к таблице (Google предупредит о непроверенном приложении: выберите «Дополнительно» → «Перейти»).
4. Скопируйте адрес веб-приложения, он заканчивается на `/exec`.
5. Впишите его в файл `config/sheets.json`: `{"url": "https://script.google.com/macros/s/.../exec"}`.
6. Откройте приложение, выйдите из аккаунта и войдите снова (или создайте аккаунт). В окне 👤 появится блок «Облако».

## Курсы валют в той же таблице: резерв, если интернет-источники недоступны

Некоторые операторы блокируют Мосбиржу, а иногда не открывается и сайт ЦБ. Тогда приложение берёт курсы доллара, евро и юаня с листа «Курсы» вашей же таблицы. Новую таблицу создавать не нужно: лист появится сам. Он выглядит как обычная таблица: строка — день, графы — «Дата», по пять граф (откр, макс, мин, закр, объём) для USD, EUR и CNY, затем «Источник» по каждой валюте и «Обновлено» (в строке 2).

Как включить (если вы уже делали шаги выше):

1. Откройте Apps Script таблицы, замените код на новый `sheets/Code.gs` и сохраните.
2. В списке функций вверху выберите `installDaily` и нажмите «Выполнить». Google попросит новое разрешение «подключаться к внешним службам»: разрешите. Функция создаст ежедневный триггер (около 7 утра) и сразу заполнит лист «Курсы».
3. Нажмите Развернуть → Управление развёртываниями → значок карандаша → Версия: «Новая версия» → Развернуть. Адрес `/exec` не меняется.
4. Проверка: откройте в браузере адрес `/exec?a=pub`. Должен показаться список с полями `USD`, `EUR`, `CNY`. Те же цифры видны на листе «Курсы».

Если раньше у вас появился лист `Public` (предыдущая версия), его можно удалить: больше он не используется.

Как это работает:

- Раз в сутки триггер `dailyFx` берёт курсы с Мосбиржи (свечи по фьючерсам), а если она недоступна, официальные курсы ЦБ (только закрытие). Результат пишется на лист «Курсы».
- Если данным в таблице больше 20 часов, их обновит запрос от любого устройства (`pubrefresh`).
- Приложение сначала пробует Мосбиржу, затем ЦБ (оба напрямую и через прокси), затем таблицу. Если не ответило ничего, оно показывает последние данные, сохранённые на устройстве, с датой.
- Лист «Курсы» общий для всех пользователей и не содержит личных данных. Вручную править его можно, но следующее обновление перезапишет данные.

## Как это устроено

- В таблице появятся листы `Users` (имя, хеш проверки пароля, дата создания, версия), `Data` (имя, ключ, часть, значение) и «Курсы». Пароли не хранятся: приложение считает из пароля отдельный ключ, а таблица хранит только его хеш.
- Владелец таблицы технически видит записи пользователей (журнал, подборки). Не давайте доступ к таблице посторонним.
- Один неверный пароль считается попыткой: после 5 попыток по имени вход блокируется на 10 минут.
- Если изменить код `Code.gs`, создайте новую версию развёртывания, иначе изменения не вступят в силу.
- Квоты Google для бесплатных аккаунтов ограничивают число запросов в сутки, для личного пользования и нескольких человек этого достаточно.
